# Architecture Decision Records

LightTools uses Architecture Decision Records for changes that cross the architectural boundaries defined in `docs/product/SPECS.md`.

## Naming

```text
ADR-0001-short-decision-title.md
```

## Required sections

- Status
- Context
- Decision
- Alternatives considered
- Security impact
- Performance impact
- Commercial/licensing impact
- Rollback strategy

An accepted ADR is part of the product architecture contract and should be linked from the pull request that implements it.
